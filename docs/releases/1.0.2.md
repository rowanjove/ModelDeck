# ModelDeck v1.0.2 发布说明

**ModelDeck v1.0.2** 带来了深度的代码审查修复、全站工作区视觉规范统一、API 调试器界面增强、新手引导向导交互优化，以及全套高保真界面截图与文档刷新。

---

## 🛠️ 重点更新与修复

### 1. API 调试器视觉与交互重构
- **高对比度配色修复**：修复 SSE 流式事件数据块在浅色主题下文字发白不可读的问题，统一使用设计系统标准文本色 `var(--ink)`。
- **cURL 命令与响应头优化**：优化 cURL 导出文本与响应头键名对比度，一键复制按钮与保存预设弹窗全面对齐 Studio Emerald 品牌强调色 `var(--accent, #0e6b4f)`。
- **预设库与操作流对齐**：修复自定义预设保存弹窗的取消与确认按钮样式，提升 API 原型调试体验。

### 2. 全局工作区视觉规范与头部排版统一
- **统一 Eyebrow 与标题**：规范所有核心模块（智能对话、多模型对比、文本生成、图像工作台、视频工作台、音频工作台、自动化工作流、全局聚合检索、模型管理、系统设置、API 调试器）的 eyebrow 层级标识与 18px 主标题。
- **消除视觉跳跃**：移除各工作区顶部的多余 margin，统一操作按钮间距，整体视觉体验更加专业整洁。

### 3. 新手配置向导交互增强
- **智能弹窗记忆**：配置向导跳过处的“以后不再提醒”勾选状态与本地存储持久化同步，已配置模型或主动勾选后不再频繁弹窗。
- **收敛入口设计**：将左侧主导航的新手向导按钮收敛至「系统设置」右上角常驻入口，保持侧边栏轻量纯粹。

### 4. 全套高清截图与文档更新
- **12 张全模态高保真截图**：使用无损浏览器自动化在标准 1440×900 视口下捕获并更新了所有核心界面截图。
- **文档补充**：在 `README.md` 中新增了全局聚合检索（Unified Search）与 API 调试器（API Debugger）的图文功能预览。

## ⚙️ 运行环境与升级建议

- **系统要求**：Windows 10 / Windows 11 (64-bit)，需具备 Microsoft Edge WebView2 Runtime。
- **数据安全**：本地数据库与素材数据默认保存在 `%APPDATA%\local.modeldeck`，覆盖安装或更换免安装 EXE 不会丢失现有数据。API Key 统一接入 Windows 凭据管理器（DPAPI 加密保护）。
- **质量验证**：177 项 Rust 单元与集成测试、40 项前端自动化测试、多视口响应式检查与 Windows 原生打包冒烟测试全项通过。
