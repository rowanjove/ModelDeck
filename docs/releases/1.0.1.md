# ModelDeck v1.0.1

本版包含首次配置向导、资产溯源、顺序工作流校验、诊断改进，以及发布前检查发现的安全与任务恢复修复。

## 修复

- 数据库备份拒绝覆盖已有文件，避免误选目标导致数据丢失。
- 应用重启后，未提交的遗留任务标记为已中断，提示手动重新发起，避免永久排队。
- 修改 Provider 的 Base URL 且未重新输入 API Key 时，移除旧凭据绑定，避免向新端点发送旧密钥；数据库更新失败时恢复原绑定和凭据。
- 工具确认绑定具体参数并只允许执行一次；文件读取和目录浏览默认需要确认。
- 打包归档仅接受当前版本的安装器，修复旧包被标成新版本的风险；CI 构建实际 NSIS/MSI 安装包。
- 前端输出与发布归档目录分离，避免历史安装器被嵌入 EXE，导致体积膨胀和编译内存不足。
- 更新应用图标、侧栏与首次向导文案。

## 升级

需要 Windows 10/11 x64 和 Microsoft Edge WebView2 Runtime。提供免安装 EXE/ZIP、NSIS 安装器，以及中文和英文 MSI。

升级前请备份 `%APPDATA%\local.modeldeck`。数据保存在当前用户的应用数据目录，密钥通过 Windows 系统凭据库保存。此次更新包含增量数据库迁移；回退前建议保留备份，不保证旧版支持新版的所有字段与功能。更改 Provider 地址后请重新输入该端点的密钥。

## 验证范围与限制

实际命令和打包验证结果见 [发布核验记录](../dev/RELEASE_VERIFICATION_1.0.1.md)。自动化协议测试使用模拟服务，不等同于真实云端、ComfyUI 或 GPU 生成验收；安装向导操作、断网冷启动和完整 GUI 交互尚未验证。程序未签名，Windows 可能显示 SmartScreen 提示。

重启时保留远端任务 ID 和计费风险提示，但不自动继续远端轮询。未知提交任务需先在服务商后台核验，再决定是否重新生成。自定义价格仍按模型标识存储，同名模型跨 Provider 的独立价格规则尚不支持；费用显示为估算，服务商账单为准。

发布附件中的 `SHA256SUMS.txt` 提供完整校验清单，`release-metadata.json` 记录源码提交与产物信息。
